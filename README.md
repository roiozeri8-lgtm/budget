# ניהול תקציב אישי

אפליקציה לניהול תקציב, בעברית. היא עובדת באייפון (כאפליקציה על מסך הבית) ובמחשב.
**הנתונים נשמרים רק במכשיר** — שום תנועה לא נשלחת לשרת. האתר ב-GitHub מכיל רק את הקוד.

כתובת: https://roiozeri8-lgtm.github.io/budget/

## התקנה

- **אייפון:** פותחים את הכתובת ב-**Safari** ← כפתור השיתוף ⬆ ← **"הוספה למסך הבית"**.
  פותחים תמיד מהאייקון (Safari מוחק נתונים של אתרים שלא נפתחו 7 ימים; אפליקציה במסך הבית מוגנת מזה).
- **מחשב:** פותחים את הכתובת בדפדפן, או לחיצה כפולה על `start.bat` (גרסה מקומית — הנתונים שלה נפרדים).

## הזנת תנועות

- **ידנית:** כפתור **＋** (בטלפון — באמצע הסרגל התחתון; במחשב — גם המקש `+`).
  מקלידים סכום ותיאור, והקטגוריה מוצעת לבד (✨). אפשר לבחור "היום" / "אתמול".
  ב"אפשרויות נוספות": הערה, **תנועה קבועה** (נוצרת לבד כל חודש), **עסקה בתשלומים** (הסכום מתחלק על כמה חודשים),
  חיוב כרטיס אשראי מרוכז, זיכוי.
- **Apple Pay:** קיצור באייפון רושם כל תשלום לקובץ, ובמסך **ייבוא** בוחרים את הקובץ.
  ההגדרה (פעם אחת) מוסברת ב**הגדרות ← קליטה מ-Apple Pay**. תשלומים שכבר נקלטו מדולגים לבד.
- **צילום מסך מהבנק:** במסך **ייבוא** בוחרים צילום, מסמנים עו"ש או כרטיס אשראי ולוחצים "פענוח".
  הפענוח נעשה במכשיר; שורות לבדיקה מסומנות בצהוב.

בכל ייבוא מוצגת טבלת בדיקה, ושום דבר לא נשמר עד **"אישור ושמירה"**. כפילויות מסומנות באדום —
גם כשאותה עסקה הגיעה ממקור אחר (ידני / Apple Pay / בנק), ואז מוצע למזג.

## מסך הבית

- **נשאר לך להוציא** — מול התקציב הכולל (אם הוגדר), אחרת מול ההכנסות של החודש; כולל כמה מותר **ליום** עד סוף החודש.
- **תחזית לסוף החודש** — חיובים קבועים ותשלומים נספרים במלואם, והוצאות יומיומיות לפי הקצב עד עכשיו
  (קנייה גדולה חד-פעמית נספרת פעם אחת).
- **תובנות** — חיובים שחוזרים כל חודש (מציע לסמן אותם כקבועים), קטגוריות שחרגו מהממוצע שלך.
- **לאן הלך הכסף** — לכל קטגוריה: סכום, תקציב (ירוק / צהוב מ-80% / אדום מעל 100%) והשוואה לממוצע. לחיצה מציגה את התנועות.
- **חיובים צפויים** — תשלומים וחיובים קבועים של החודשים הבאים.
- **חצי שנה אחרונה** — הכנסות מול הוצאות.

## הגדרות

- **חודש ותקציב כולל** — אפשר להתחיל את החודש התקציבי ביום אחר (למשל ב-10, כשהמשכורת נכנסת).
- **קטגוריות ותקציבים** — אייקון, צבע, שם ותקרה חודשית.
- **כללי סיווג** — מילת מפתח ← קטגוריה. המילה הארוכה קובעת; עד 3 אותיות — מילה שלמה בלבד.
  כשמתקנים קטגוריה של תנועה, האפליקציה מציעה ליצור כלל.
- **תנועות וחיובים קבועים** — עריכה, השהיה וביטול.
- **נעילה ופרטיות** — קוד, ובאייפון גם Face ID. נפרד לכל מכשיר.

## גיבוי וסנכרון בין מכשירים

**הגדרות ← גיבוי וסנכרון.**

- **ייצוא גיבוי** — באייפון: "שמירה בקבצים" ← iCloud Drive. במחשב: נשמר בהורדות.
- **מיזוג מקובץ גיבוי** (= סנכרון) — מוסיף ומעדכן בלי למחוק את מה שהוזן במכשיר; מחיקות עוברות גם הן.
  בשני הכיוונים: ייצוא במכשיר א' ← מיזוג במכשיר ב' ← ייצוא במכשיר ב' ← מיזוג במכשיר א'.
- **שחזור מלא** — מחליף את כל הנתונים במכשיר בנתונים שבקובץ.

האפליקציה מזכירה לגבות אם עברו שבועיים.
